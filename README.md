Project Title
Dynamic Website (CUITM216 Submission)

 Description
This project is a dynamic, responsive website built with HTML, CSS, JavaScript, and PHP.
It demonstrates how client‑side and server‑side scripting work together to deliver interactive content, user authentication, and database integration.
The system is designed for learning and exam practice, showcasing modern web development techniques.

 Features
Responsive layout using CSS media queries

Dynamic content rendering with JavaScript

User login and registration system (PHP + MySQL)

Interactive forms with validation

Database integration for storing user and product data

Modular structure for scalability

 Tech Stack
Frontend: HTML5, CSS3, JavaScript

Backend: PHP

Database: MySQL

Version Control: GitHub

 How to Run
Clone the repository:

Code
git clone https://github.com/nabothai/dynamic-website.git
Place files in the htdocs folder of XAMPP (or any PHP server).

Start Apache and MySQL in XAMPP.

Import the provided SQL file into phpMyAdmin to set up the database.

Visit http://localhost/dynamic-website/index.html in your browser.

 Example Workflow
Step 1: User registers and logs in.

Step 2: Dynamic content loads based on user interaction.

Step 3: Data is stored/retrieved from MySQL.

Step 4: Responsive design adapts to different devices.

 Security & Ethics
Passwords hashed using password_hash() in PHP.

Input validation to prevent SQL injection.

Promotes ethical e‑business practices with transparency and user consent.
